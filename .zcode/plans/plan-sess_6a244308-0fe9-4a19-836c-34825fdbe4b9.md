# App-wide redesign: light-first minimal + lobby layout fix

## Context

The app (multiplayer Minesweeper/Sudoku/Klondike/FreeCell, React + Vite, single global stylesheet) has a heavy "tactile dark casino" look — 5,929-line `styles.css`, 130 tokens, glass blur, gradient washes, glows, skeuomorphic shadows, 7.5–9.5px micro-labels — plus structural duplication: 6 copy-pasted full-screen status screens, 3 near-identical Results components, 3 hand-built game HUDs, invite UI rendered 3 ways. The room lobby page has confirmed layout problems: room code shown 4× (incl. an orphaned floating block top-right), unbalanced columns (right side much shorter), competing amber CTAs, clipped player names, absolutely-positioned "edit" tags overlapping content, and a weak 3-fragment tips footer.

**Decisions (user-confirmed):** light-first flat minimal visual language (dark = secondary theme, both kept) · balanced two-column lobby · consolidate duplicated markup (no feature/behavior changes) · CSS rewritten from scratch.

## 1. New design language — rewrite `src/client/styles.css` in place

Replace the whole file (~5,929 → target ~2,400 lines), organized: tokens → reset → primitives → home → join → room chrome → lobby → games (shared + per-game) → countdown → results → modals → media queries.

**Tokens (light = `:root` default now, `[data-theme="dark"]` overrides ~30):**
- Neutrals: `--bg` (warm off-white ~#faf9f7), `--surface` (#fff), `--surface-muted`, `--line`, `--line-strong`, `--text` (near-black), `--text-muted`, `--text-faint`
- One accent: amber, reserved for selection/highlight/game state (live dot, chosen game, number colors). **Primary buttons use high-contrast neutral** (solid near-black w/ white text in light; off-white w/ black text in dark) — no gradient buttons, no glow shadows
- Semantic: `--success`, `--danger` (+ soft backgrounds)
- Scale tokens: radii `--radius-sm/md/lg` (8/12/16) + pill; shadows `--shadow-raised` only (modals/popovers — everything else is border-only); mono kept for codes only
- Game sub-tokens (tiles `--n1..--n8`, sudoku cells, card faces/backs) re-tuned for light surfaces, kept minimal per game

**Rules of the language:** solid surfaces + 1px borders (no `backdrop-filter`, no gradient backgrounds, no inset highlights), one `.eyebrow`-style label class (11px minimum — replaces ~20 micro-label copies), one pill class, one well-button class, one `.panel` card class. Consolidate breakpoints to 3: 960 / 720 / 480.

**Theme default flip:** `src/client/lib/theme.ts` + `public/theme-init.js` — new users get **light** (drop OS-follow; stored choice still respected), update `theme-color` metas in `index.html` and `theme.ts`. Toggle stays.

## 2. Room lobby fix — `src/client/components/Lobby.tsx` (restructure)

Balanced two-column per approved mockup:
- **Intro row:** eyebrow + `h1` + one-line status; identity chip (avatar + "You're **name**" + change button) inline. **Delete** `.lobby-code-block` (header bar already shows the code) and `.lobby-tips` footer
- **Game switcher:** host-only row of 4 flat segmented buttons (drop `em` kicker sublabels)
- **Left column:** players panel (simplified chips — avatar + name + crown + status; `min-width:0` + proper ellipsis fixes the clipped-name bug; remove the absolute-positioned `edit` tag, whole self-chip stays clickable; one "open seat" style, no "+5 more" chip — count shown in panel head) + InvitePanel
- **Right column:** single setup/start panel (host): heading, inline quick settings (size/difficulty/draw + seat stepper), **board-spec facts merged in** as data-driven rows (`facts: [label, value][]` config replaces the 3 hand-written `.board-facts` JSX blocks + board-summary panel deleted), Start CTA. Non-host: waiting card
- Keep `.last-game` strip and mobile fixed start bar (restyled, single CTA)

## 3. Markup consolidation (behavior unchanged)

- **`src/client/pages/RoomPage.tsx`:** replace `LoadingRoom`/`JoiningRoom`/`MissingRoom`/`NetworkRoom`/`FatalRoom`/`JoinProblem` with one `<RoomStateScreen>` (icon/title/body/action props); same for `InvalidCode`/`NotFound` in `App.tsx` if it stays clean
- **`src/client/components/Results.tsx`** (584 lines): one `<ResultsCard>` with per-game config (metrics, stat columns, result text) — deletes ~2/3 of the file
- **New `src/client/components/GameHud.tsx`:** shared HUD (left/center/right slots) replacing the three hand-built `.game-hud` blocks in `Game.tsx`, `SudokuGame.tsx`, `SolitaireGame.tsx`; also dedupe the duplicated `sudoku-mode`/`solitaire-mode` CSS and the unused `hud-left` class
- **`src/client/components/InvitePanel.tsx`:** one panel used inline (lobby) and in the header-Invite modal; the "Show join screen" projection stays as a large-format variant of the same panel instead of a third parallel UI
- **`src/client/components/RoomChrome.tsx`:** simplify the top bar (merge StatusPill + player count into one cluster; same menu items/actions)

## 4. Other screens (markup mostly unchanged, restyled to new language)

- **`src/client/pages/Home.tsx`:** simpler hero (headline, create/join actions, quick-join form); replace the 36-tile `HERO_TILES` decorative board with a quiet minimal element (small static board or game-icon row — decide during implementation); flat game cards
- **`JoinPage.tsx`, `Countdown.tsx`, `SettingsSheet.tsx`, `ProfileModal.tsx`, `ui.tsx` (Logo/Modal/Toast/Spinner/StatusPill/Confetti), `Board.tsx`/`SudokuBoard.tsx`/`SolitaireBoard.ts`:** class-level restyle only — logic, keyboard/cursor/drag interactions, and board geometry untouched
- Server, `shared/types.ts`, and all tests untouched
